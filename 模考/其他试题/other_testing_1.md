1、项目经理是跨职能敏捷团队中的一员。项目经理被分配了一个具有多个功能的软件项目，该项目将花费团队大约一年的时间来完成。首席执行官坚持认为，解决方案需要满足年底的业务目标，也就是6个月后的目标。项目经理应该做什么来使干系人的需求和期望一致？

- [x] A.与干系人合作，创建优先待办事项列表事项并发布路线图

- [ ] B.将要求修改为可在6个月内完成的要求

- [ ] C.实施快速跟进和赶工活动，在6个月内完成项目

- [ ] D.在日常scrum会议中包括所有干系人，让他们了解情况

2、一位项目经理刚刚被指派到一个有两个主要可交付物的项目。两个可交付物具有相同的优先级，并将同时交付。团队中的许多人都在抱怨缺乏关于哪一个可交付物需要首先完成的信息。项目经理应该怎么做？

- [ ] A.由于难以同时执行两个可交付物，要求关键干系人取消项目

- [ ] B.要求团队首先开始处理最容易的可交付物，这样他们就可以获得执行第二个可交付物的经验

- [x] C.与项目发起人和主要干系人会面，评估每个可交付物对组织的价值，并设定执行优先级

- [ ] D.要求项目团队同时执行两个可交付物，因为这是项目章程要求和批准的

3、一名团队成员与职能经理分享了团队中的另一名成员绩效的负面情况，而这些情况已经在回顾会议中讨论过了。项目经理发现该情况之后，应该采取以下哪两项行动？（选两项）

- [ ] A.邀请职能经理参加下一次回顾会议

- [x] B.联系该团队成员，并说明哪些信息可以在团队外分享

- [x] C.召集所有团队成员以审查团队内部安全环境的规则

- [ ] D.联系产品负责人，针对该情况进行讨论

E.联系发起人，对该情况进行审查

4、一个典型的高绩效团队成员开始表现出绩效下降以及在会议上对其他团队成员的一些攻击性行为（some aggressive behaviors挑衅行为）。项目经理已经和这个人在这个项目上共事好几个月了，以前从未见过这种类型的行为。项目经理应该怎么做?

- [x] A.与个人讨论项目经理的观察，以确定他为什么这样做

- [ ] B.与其他团队成员讨论个人的行为，以确定他们是否注意到并知道正在发生什么

- [ ] C.参加更多的团队会议，更密切地观察团队，以确定根本原因

- [ ] D.与团队成员的职能经理以及人力资源(HR)讨论他们的表现，并讨论下一步

5、一个项目需要采购大量的设备，在其他活动开始之前，这些设备需要在现场。采购部门有一个漫长的审批程序。项目经理应该怎么做？

- [ ] A.要求项目发起人加快供应商选择过程

- [ ] B.联系为上一个项目提供类似设备的供应商

- [ ] C.使用现有设备，以后用新设备代替

- [x] D.与采购小组合作，寻找替代办法

6、一位项目经理最近被派去拯救一个奥林匹克设施的高优先级项目。这个项目已经落后于计划，合同上有重罚。前项目经理与项目团队成员和一些干系人有许多冲突。项目经理首先应该做什么？

- [ ] A.审查项目进度，并申请应急储备，以终止项目

- [x] B.与项目团队和干系人会面，确定问题的根本原因，并制定解决方案

- [ ] C.与前项目经理在非公开会议上审查经验教训登记册

- [ ] D.与项目团队会面，确认职权并重新分配项目任务，以便及时交付

7、项目经理正在管理一个需要专门架构服务的项目。该项目被认定为该组织的高风险项目。项目经理与高度专业化的外部架构师一起工作。然而，架构师很快就会辞职，因为他们接受了一份来自另一家公司的邀请。

项目经理下一步该怎么做?

- [x] A.与项目团队讨论，评估影响，并决定适当的后续行动

- [ ] B.询问架构师他们新雇主的联系方式，并打电话给他们的客户经理

- [ ] C.打电话给客户经理，给他们提供奖励，让他们留住专家

- [ ] D.将问题升级到采购部门，并要求他们与供应商公司讨论



8、项目管理办公室 (PMO) 指派一名专精于混合方法的项目经理处理一个从成本和进度角度来看都偏离轨道的预测项目。由于项目经理正在加快项目进度，该项目遇到了进一步的延误。利益相关方要求高级管理层更换项目经理。项目经理应该如何处理这种情况？

- [ ] A.与利益相关方交流，以更好地了解他们的需求并重新设定期望

- [x] B.与利益相关方会面，了解他们的担忧并制定解决问题的行动计划

- [ ] C.将利益相关方的问题上报给管理团队，并寻求解决冲突的帮助

- [ ] D.继续在项目上工作，直到利益相关方和管理层做出决定

1、A

2、C

3、BC

4、A

5、D

6、B

7、A
