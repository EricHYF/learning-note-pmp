## 第1题 (✅)

1、在一个正在进行的项目中，一直是项目主要联系人的客户告诉项目经理，由于他们的日程安排很忙，他们将介绍一名新的联系人。该新联系人也将在今后做出关键决策。项目经理接下来该做什么？

- [ ] A.沟通管理计划。
- [x] B.用新联系人的详细信息更新干系人登记册。 (==正确答案==)
- [ ] C.将新联系人告知项目团队。
- [ ] D.请求与客户和新联系人会面。

> 答案解析:
> 干系人登记册记录了各种干系人信息，包括（但不限于）：干系人名单、评估结果和分类情况，
> B正确。ACD均在B之后。

## 第2题 (❌)

2、在某产品开发过程中，产品经理发现项目相关方之间发生冲突，导致对可交付成果和输出的批准发生延误。项目经理应关注哪个方面？

- [ ] A.查阅商业论证，并识别范围内存在的差距
- [x] B.提高项目更新会议的举行频率，以便让相关方随时了解项目情况 (==正确答案==)
- [ ] C.重新查阅相关方参与计划，重点关注 被忽略的相关方
- [ ] D.重新查阅项目管理计划，确保可交付成果按时交付

> 答案解析:
> A商业论证记录预期的商业价值，与题干的冲突无关，排除。
> B相关方通过会议能及时了解项目进展，从而能更加积极得处理相互之间的冲突，正确。
> C审查相关方参与计划是可行的，但双方之间的冲突，不能只关注被忽略的相关方，且题干未涉及被忽略的相关方，属于延伸题干，排除。
> D忽视了相关方间的冲突，排除。

## 第3题 (✅)

3、项目经理正在主持一场有关键相关方、项发起人和产品负责人参加的会议，以定义将在下一个迭代后发布的功能，考虑到上一个迭代期间某些可交付成果未完成，这场会议旨在审查产品待办事项列表的优先级在该会议期间，为了审查并更新产品待办事项列表的优先级，应首先考虑哪两项？（选择两项）

- [x] A.开发的复杂性和成本 (==正确答案==)
- [ ] B.重复使用来自另一件产品的组件
- [ ] C.行业趋势和技术方法
- [x] D.根据商业价值延期推出某些功能的成本 (==正确答案==)
- [ ] E.各项功能被列于待办事项列表的时间长度

> 答案解析:
> 用户故事的排序，需要考虑价值、成本、延期成本等。价值越高的优先级越高；对于同等价值和时间要求的用户故事，成本低、交付速度快的优先级高。延期成本是当工作或里程碑延期交付所产生的财务成本。若想知道一个产品、一个特性的延期成本，只需要问一个问题："如果我们晚交付一个月的话，会给我们造成什么损失？"或者正向问法："如果我们提前交付一个月的话，会给我们带来什么价值？"。价值最高的或损失最大的优先级越高。AD正确。
> B重复使用组件可降低成本，与优先级排序关系不大，排除。
> C行业趋势可以参考但不是优先级排序必须考虑的，排除。
> E功能不是越早纳入待办事项列表，优先级就越高，排除。

## 第4题 (✅)

4、A项目对公司至关重要，必须在九个月内完成。项目章程已经签署，但项目范围说明书尚未编制。管理层要求项目经理在项目范围说明书未获批的情况下推进项目。项目经理接下来该做什么？

- [ ] A.以项目章程作为输入开始项目，以节省时间。
- [ ] B.拒绝开展项目，因为管理层未遵循标准的项目管理实践。
- [ ] C.将问题上报项目发起人，并将之记入风险登记册。
- [x] D.与管理层会面，解释在没有项目范围说明书的情况下开展项目可能会造成哪些问题。 (==正确答案==)

> 答案解析:
> 关键词：范围说明书未获批。范围说明书记录了整个范围，代表项目相关方之间就项目范围所达成的共识。为便于管理相关方的期望，项目范围说明书可明确指出哪些工作不属于本项目范围。
> D对管理层的要求进行风险分析，管理层了解后更容易支持项目工作，正确。
> A以项目章程作为输入开始项目意味着忽略了范围说明，容易引发范围蔓延，排除。
> B应该在分析风险后再拒绝，在D之后，排除。
> C上报发起人，消极，排除。

## 第5题 (✅)

5、某敏捷项目经理想把需求文件转变为长篇故事、能力、功能和故事。项目经理应该在几个迭代中估算故事持续时间？

- [ ] A.四个迭代
- [ ] B.三个迭代
- [ ] C.两个迭代
- [x] D.一个迭代 (==正确答案==)

> 答案解析:
> 在 Sprint 计划会议中，开发团队挑选出足够量的工作，以此来预估他们在即将到来的 Sprint 中能够完成。开发团队估算挑选本冲刺的工作量，
> D正确。
