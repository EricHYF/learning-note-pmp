## 第1题 ( ✅ )

1、团队正在实施一个通信系统，此时客户表示他们正考虑关闭该项目。项目经理安排与客户举行紧急会议，以了解该项目为何存在风险。项目经理可使用哪两种工具或技术影响客户的决定，以便使项目继续运作。（选择两项）

- [ ] A.自主决策
- [ ] B.备选方案分析
- [x] C.多标准决策 (==正确答案==)
- [ ] D.成本效益分析
- [x] E.投票 (==正确答案==)

> 答案解析:
> 关键词：影响客户的决定。题目考察的是决策的具体工具。决策工具与技术包括多标准决策技术和投票，CE正确。自主决策速度快，但容易出错，且是客户考虑关闭项目，A排除。B对于超出项目团队决策权的决策，项目团队可以调查备选方案，考虑每个备选方案的影响，并将决策升级到拥有适当职权的人员。题干未涉及更高的决策层级，排除。D成本效益分析是数据分析的工具，排除。

## 第2题 ( ✅ )

2、一位项目经理加入了一个团队，该团队向客户提供定制的企业资源规划系统。开发团队发现了一个潜在的设计问题。在与项目负责人和团队成员对该问题进行回顾之后，所有人均同意对设计进行修改，以避免在部署时出现系统缺陷。该设计已获批。项目经理接下来该做什么？

- [ ] A.提出变更请求，并征得项目负责人正式批准
- [x] B.将问题告知客户，并遵循变更请求流程。 (==正确答案==)
- [ ] C.修改设计规格，并将之转交给开发团队，以便重新编程。
- [ ] D.进行概念验证，确保重新修改的设计中不存在任何问题

> 答案解析:
> 关键词：该设计已获批。考察的知识点为变更控制。变更控制会议上所做的决定将被记录下来并传达给有关的干系人。B正确。A该步骤已经完成，排除。C是B中的遵循变更请求流程的具体内容，在B之内。D属于对变更进行分析的步骤，已经完成，排除。

## 第3题 ( ✅ )

3、一个项目接近尾声。应急时间已经用完。为了确保能够按时在预算之内实现最终可交付成果，项目经理要求其团队严格按流程开展工作，但这引发了团队成员的抗拒。项目经理该做什么来应对这种愈来愈强烈的抗拒？

- [x] A.向团队成员说明他们可以使用哪些具体的工具和技术来按时完成项目。 (==正确答案==)
- [ ] B.加快项目进度计划，让项目团队成员加班加点在新设定的期限前完成项目。
- [ ] C.说服团队成员采用某一具体方法按时完成项目。
- [ ] D.通过发放激励费用的鼓励方式，使团队成员按时完成项目

> 答案解析:
> 关键词：确保预算内，严格按照流程开展工作，抗拒。B加班加点完成项目，必然会引发成本增加，不一定能确保在预算内完成。排除。愿意寻求自主权的项目团队成员将表现得更为出色，A提供了自主选择工具和技术的权力，正确，C排除。D奖励针对优良的行为，目前团队成员处于抗拒，奖励不合适，排除。

## 第4题 ( ❌ )

4、项目经理被指派开展一个项目，该项目所在公司正在向敏捷型组织过渡。并非所有相关方都对该项目有信心，一些相关方希望在项目早期阶段即对整个项目作出定义和规划。但项目发起人需要快速获得成功，以确保项目继续开展。项目经理该采用哪种方法？

- [ ] A.预测型方法，因为这样可以取悦高级相关方。
- [ ] B.敏捷型方法，因为这样可以更早地提供有效功能。
- [ ] C.预测型方法，因为这样可以让所有相关方看到效益。
- [x] D.混合型方法，因为这样可以减轻相关方的顾虑。 (==正确答案==)

> 答案解析:
> 关键词：在项目早期阶段即对整个项目作出定义和规划，需要快速获得成功。前者倾向于采用预测型方法，后者倾向于采用适应型方法，要兼顾双方的意见，可以采用混合型。D正确。

## 第5题 ( ✅ )

5、项目经理正在领导一个自动化项目。项目团队成员集中办公，包括来自技术和业务部门的人员。项目经理发现个人差异和工作方式对项目产生了负面影响。项目经理应该如何处理这个问题？

- [ ] A.制定进度计划，确保存在个人差异的员工不会在一起工作。
- [ ] B.邀请不同部门的职能经理解决他们的个人差异。
- [ ] C.使用不需要集中办公的项目方法
- [x] D.与团队会面，并就团队成员的期望达成一致。 (==正确答案==)

> 答案解析:
> 关键词：个人差异和工作方式产生负面影响。利用排除法，AC回避解决个人差异和工作方式的问题，排除。B应由项目经理来解决，而不能推给职能经理，排除。团队成员经常来自不同的行业，讲不同的语言，项目经理应在整个项目生命周期中致力于发展和维护项目团队，并促进在相互信任的氛围中充分协作。通过会面达成一致进而产生信任，D正确。
