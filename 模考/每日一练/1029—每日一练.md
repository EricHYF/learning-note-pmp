## 第1题 (✅)

1、在没有商业论证的情况下，高级管理层要求项目经理开展新的项目。在这种情况下，项目经理应该指导团队怎么做？

- [ ] A.等待商业论证文件完成后再继续
- [ ] B.开始制作项目管理软件
- [x] C.收集学习商业论证的要求，准备向发起人提案 (==正确答案==)
- [ ] D.收集客户反馈，用于编辑项目管理计划。

> 答案解析:
> 关键词：没有商业论证。可知，项目未正式批准，项目经理和团队不能直接开展项目工作，但可以为项目的执行做好准备。BD排除。A项目章程审批通过后才能开展项目工作，而非商业论证，排除。项目发起人通常负责项目商业论证文件的制定和维护。项目经理负责提供建议和见解。C项目为推进项目，准备所需的资料以编制商业论证给发起人审批，积极，正确。

## 第2题 (✅)

2、项目经理负责一个网络维护项目，该任务会造成公司断网4~6个小时。项目经理正在梳理断网会影响的相关方并准备沟通。目前公司已确认的沟通方式有网站宣传、邮件沟通、电话沟通、会议沟通等多个沟通方式。项目经理应该怎么沟通？

- [x] A.制定一种或多种沟通方法，根据相关方的影响评估具体的沟通方式。 (==正确答案==)
- [ ] B.咨询实施该项目的前项目经理，了解他的沟通方式
- [ ] C.利用公司现有的全部沟通方式进行沟通。保证信息全覆盖
- [ ] D.利用周末进行网络维护，这样就不用发送通知信息。

> 答案解析:
> 沟通方法的选择应具有灵活性，以应对相关方社区的成员变化，或成员的需求和期望变化。A针对不同相关方使用有针对性的沟通方式，A正确。B题干未涉及前项目经理，排除。C使用全部沟通方式可能是低效的，排除。D消极，排除。

## 第3题 (✅)

3、团队原本每日举行站立会，因为某些原因，50%的人无法到会参加，项目经理就要不要举行站立会做什么选择？

- [x] A.虚拟团队形式 (==正确答案==)
- [ ] B.每周项目报告
- [ ] C.项目经理一对一询问
- [ ] D.项目团队成员自己发送进度报告

> 答案解析:
> 关键词：50%的人无法到位参加。可知团队成员无法面对面开站会，可借助技术手段采用虚拟团队形式。A正确。B每日站会不能改为每周，交流不及时，排除。C团队成员利用每日站会对彼此做出小的承诺，发现问题，并确保团队工作顺利进行。站会是团队成员互相承诺，而非向项目经理承诺，排除。D站会是为了承诺和发现存在问题，而非仅仅了解进度，排除。

## 第4题 (❌)

4、项目经理被授权领导建立一个新产品，以便供整个组织使用，组织要求完成项目的标准是及时的保证所有相关方能采用这个新产品，项目经理应该怎么做？

- [ ] A.发起人通知到每个相关方，让他们按时采用这个新产品
- [ ] B.与所有相关方进行富有建设性的讨论，以商定一个新方案，解决新产品的上线时间 (错误)
- [ ] C.考虑到组织的庞大和干系人的多且复杂，与CEO商定并发布上线时间
- [x] D.考虑到组织的庞大和干系人的多且复杂，与相关方沟通并请求其遵守安装部署上线时间 (==正确答案==)

> 答案解析:
> 关键词：及时的保证所有相关方能采用。AC涉及发起人、CEO，消极，排除。B中“商定新方案”，题干未涉及现有方案无法保证相关方及时采用，排除。D与相关方沟通并请求，积极，正确。

## 第5题 (✅)

5、项目经理参加一个平衡矩阵的项目，需要经常向采购部门获取绩效报告的最新信息，但是采购负责人没有空余时间。项目经理应如何解决该问题？

- [ ] A.向采购的上级询问
- [ ] B.向项目发起人
- [ ] C.要求采购部门员工提供
- [x] D.与采购负责人沟通，确定可接受的沟通 (==正确答案==)

> 答案解析:
> 关键词：没有空余时间。这是个问题，需要与相关方沟通，了解情况并找到解决方案。D正确。A上级B发起人，均消极，排除。C项目经理无权直接要求采购部门的人员，排除。
