1、项目经理审查历史组织经验，发现客户要求审查所有变更，即使是合同中没有的变更也要审查，团队感到困扰。项目经理目前正在做规划，如何避免这种情况?

- [ ] A.制定项目管理计划约束范围
- [x] B.通过变更管理控制 (正确答案)
- [ ] C.制定范围基准 (错误)
- [ ] D.更新风险管理计划

> 答案解析:
关键词：审查变更，说明客户对变更控制非常重视，项目经理应通过变更控制流程更好的处理变更，B正确。AC明确范围约束范围，题干未涉及变更为范围方面的变更，片面，排除。D目前正在做规划，管理计划未完成，无法更新，排除。

- [ ] D.拒绝发起人，因为会影响项目正常交付。

答案解析:
《敏捷宣言》2欢迎对需求提出变更，即使在项目开发后期也不例外，敏捷过程要善于利用需求变更，帮助客户获得竞争优势，A正确。D排除。B产品经理不是敏捷中角色，排除。C题干未涉及项目是突发情况及进度延期，排除。

5、项目经理被授权组建一个虚拟团队，团队成员来自不同地区的主题专家，项目经理组建团队需要考虑哪些要素？（选3项）

- [ ] A.可能团队成员的道德和伦理存在风险，并影响项目进展
- [x] B.不同文化差异可能会导致沟通障碍 正确答案
- [x] C.不同的时区差可能会造成沟通影响 正确答案
- [ ] D.团队进度及其状态可能很难评估
- [x] E.不同的成员沟通基础技术设施可能存在一定差异 正确答案

> 答案解析:
PMBOK第7版，P147项目团队成员可能位于不同的城市、时区或国家/地区，则文化差异、时区差都需要考虑。虚拟团队往往会借助虚拟工作进行沟通协作，沟通基础技术上设施的差异，需要考虑。BCE正确。A不信任团队成员，且即使有也可以当成风险来处理，排除。D与团队的组建无关，且即使存在也可以当成风险来处理，排除。
