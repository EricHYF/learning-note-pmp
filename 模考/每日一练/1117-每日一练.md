## 第1题 (✅)

1、项目发起人指示项目经理起草项目章程。项目发起人要求项目经理让特定干系人参与进来，以便提供必要的资源。但是，干系人拒绝参与，因为干系人认为使用项目可交付物没有好处。项目经理该做什么来解决这个问题？
- [ ] A.由于问题的政治性质，上报给项目发起人。
- [x] B.与干系人会面，讨论可交付物的影响。 (==正确答案==)
- [ ] C.改善与干系人的沟通，以便未来获得他们的帮助。
- [ ] D.将干系人视为风险，并与项目团队一起评估可能的解决方案。

> 答案解析:
> 关键词：干系人认为使用项目可交付物没有好处。即干系人不了解项目可交付的价值，需要通过沟通让对方了解并争取支持项目。A题干未涉及问题的政治性质，排除。B会面讨论影响，积极主动的争取相关方的支持，正确。C题干未涉及与相关方沟通不畅，且"未来"忽略了解决当前问题，排除。BD相比，应先与相关方沟通，D应在B之后，排除。

## 第2题 (✅)

2、在执行阶段，项目经理发现可交付物不符合主要干系人要求的质量规范。这导致进度绩效指数（SPI）从0.98下降到0.72，成本绩效指数（CPI）从1.5下降到 1.1。在下一次迭代期间，项目经理应采取什么措施来缓解可交付物被拒绝的问题？
- [ ] A.提交变更请求，以优先解决质量问题，从而最大限度减少对其余可交付物的影响。
- [x] B.在冲刺计划期间强化完成的定义（DoD）的定义，以便团队对期望有共同的理解。 (==正确答案==)
- [ ] C.创建一个专门的冲刺，以完成之前冲刺中的所有未达标规范。
- [ ] D.确保产品待办事项列表得到适当的优先处理，以避免导致拒绝的依赖关系。

> 答案解析:
> 关键词：不符合质量规范，下一次迭代期间。完成的定义 (DoD)是为了考虑可交付物能供客户使用，而须达到的所有准则的检查清单。B正确。A敏捷中无需走变更控制流程，排除。C未达标的规范的工作是否在下一迭代完成取决于PO设定的优先级，而非由项目经理来决定，排除。D题干未涉及依赖关系是导质量不符合规范的原因，排除。

## 第3题

3、项目团队已经成立，任务已分配给每个团队成员。所有团队成员都同意采用混合项目方法。项目经理应如何确保团队作为一个有组织的整体开展工作？
- [ ] A.为团队成员建立规则和规章制度，以及如果未能实现目标会产生的后果。(*错误*)
- [ ] B.建议团队调整他们的工作习惯和行为，以便更好地解决冲突。
- [x] C.建议团队行为并引导团队了解如何合作。 (==正确答案==)
- [ ] D.召开团队会议，讨论团队成员的优势和劣势。

> 答案解析:
> 关键词：混合方法。团队协作是项目成功的关键因素，而建设高效的项目团队是项目经理的主要职责之一。项目经理应创建一个能促进团队协作的环境，并通过给予挑战与机会、提供及时反馈与所需支持，以及认可与奖励优秀绩效，不断激励团队。C正确。团队成员尽早认可并遵守明确的规则，有助于减少误解，提高生产力。A项目经理建立的基本规则，如果未得到团队成员认可对团队凝聚力无意义，排除。B题干要求使团队作为整体开展工作，而非解决冲突，排除。D讨论优势劣势对作为一个整体工作没有直接关系，排除。

## 第4题 (✅)

4、某团队正在运用混合型方法开展一个项目，但一些相关方使他们面临很多障碍和阻碍。项目经理该做什么来提高项目绩效？
- [ ] A.将阻碍添加到问题日志和风险管理计划。
- [ ] B.让相关方与项目经理（而非直接与团队）沟通。
- [ ] C.授权团队成员消除障碍和阻碍。
- [x] D.解决和消除团队面临的障碍和阻碍。 (==正确答案==)

> 答案解析:
> 关键词：面临很多障碍和阻碍。仆人式领导有能力改变或消除这些组织障碍，为交付团队提供支持。D正确。A问题不能添加到风险管理计划，排除。服务型领导者会使项目团队免受内部和外部分心之事影响，这些分心之事会使项目团队偏离当前目标。且B强调沟通而未涉及解决，D强调消除，D更有效，排除B。C未体现项目经理的仆人式领导，排除。

## 第5题

5、某大型建筑项目的项目经理发现客户提供的蓝图似乎不完整。项目经理首先该做什么？
- [ ] A.继续使用客户提供的蓝图执行项目。
- [x] B.与客户协商确定是否应该继续执行项目。 (==正确答案==)
- [ ] C.重新安排项目的执行日期。
- [ ] D.将该问题上报给项目发起人。

> 答案解析:
> 关键词：客户提供的蓝图似乎不完整。蓝图是关于项目的未来规划，规划不完整，应与客户协商，否则无法开展后续工作。B正确。ACD在B之后，排除。
