## 第1题 (✅)

1、六个月前开始了一个敏捷项目。自项目开始以来，由于一些团队成员无法同时参加，团队成员之间在每日站会方面存在分歧。项目经理确信敏捷团队应该是自组织的，会议时间应该由团队决定。项目经理应该做什么？

- [x] A.建立团队章程 (==正确答案==)
- [ ] B.认可团队的贡献。
- [ ] C.指派一名团队负责人
- [ ] D.制定项目进度计划.

> 答案解析:
> 选A，关键字"团队成员之间在每日站会方面存在分歧"，这个问题主要是关于如何处理团队内的分歧，同时维持敏捷的自我组织原则。项目经理应该建立团队章程，团队章程可以帮助定义团队的期望、角色、职责和规则，包括如何解决分歧。

## 第2题 (✅)

2、在待办事项梳理期间，架构师因有事没有梳理完所有待办事项，项目经理应该如何处理？

- [ ] A.等待架构师完成评估
- [x] B.请求产品经理，按已规划的事项开始冲刺 (==正确答案==)
- [ ] C.直接安排团队开始冲刺
- [ ] D.请发起人批准开始冲刺

> 答案解析:
> 《敏捷实践指南》P52基于迭代的敏捷团队的多次细化讨论。《Scrum精髓》P123细化活动的最终决策人是产品负责人。根据题干可知，待办事项未完全梳理完成，后续可再进行梳理。PO可根据当前的梳理，对已完成的内容开始后续工作，B正确。《敏捷实践指南》P52在迭代中期可以进行一次或多次待办事项列表的梳理，从而为即将进行的迭代准备一些故事，C是否开始冲刺取决于梳理会的时间，排除。D发起人，排除。

## 第3题 (❌)

3、项目经理完成了对项目团队成员的绩效评估，发现有一些团队成员绩效不足。项目经理应该如何制定绩效标准？

- [x] A.根据项目团队成员的兴趣能力制定绩效标准 (==正确答案==)
- [ ] B.根据项目的特征制定绩效标准
- [ ] C.根据项目的实际情况制定绩效标准
- [ ] D.根据组织标准来制定绩效标准（错误）

> 答案解析:
> 关键词：对项目团队成员的绩效评估。PMBOK第7版P25根据个人偏好对激励方法进行裁剪有助于实现最佳的个人和项目团队绩效。PMBOK第6版P346项目经理应留意团队成员是否有意愿和能力完成工作，然后相应地调整管理和领导力方式。A正确。PMBOK第7版P95项目的KPI绩效指标要能够沟通项目状态、有助于改善项目绩效，并降低绩效恶化的可能性，BC是项目的绩效指标需要考虑的，而个人的绩效指标，可以考虑，相比A更优先，排除BC。D组织的绩效指标需要裁剪，排除。

## 第4题 (✅)

4、一个项目经理在项目执行过程中，经常和一个干系人沟通，以满足干系人的需求。这个项目经理后来提出了离职，问这个项目经理怎么能够保证新来的项目经理继续和干系人保持有效的沟通？

- [ ] A.确保干系人的工作需求，已经写入了相关方参与计划
- [ ] B.确保对这个干系人的沟通情况，已经传递给项目成员
- [ ] C.确保项目成员已经掌握干系人的特殊沟通需求
- [x] D.和下一任项目经理做好工作交接，确保新项目经理了解干系人沟通情况 (==正确答案==)

> 答案解析:
> 关键词：保持有效沟通。可推断，考察的知识点为沟通管理。对新任项目经理，项目经理应将该干系人的信息需求、偏好等列入沟通管理计划，沟通管理计划是项目管理计划的组成部分，描述将如何规划，结构化、执行与监督项目沟通，以提高沟通的有效性。D正确。A涉及的是相关方参与计划，排除。B应将干系人的沟通情况传递给新任经理，而非团队成员，排除。C题干未涉及干系人的特殊沟通需求，排除。

## 第5题 (✅)

5、在一次辅导会议中，项目组织要求一名初级项目经理简单介绍了借用挣值管理方案来管理项目的益处，初级项目经理应参考以下哪项?

- [x] A.S曲线 (==正确答案==)
- [ ] B.累积流图
- [ ] C.看板面板
- [ ] D.水晶图

> 答案解析:
> 由于成本基准中的成本估算与进度活动直接关联，因此就可按时间段分配成本基准，得到一条S曲线。对于使用挣值管理的项目，成本基准指的是绩效测量基准，与实际完成的工作量或实际支出的成本相比，就能判断项目的进展状态。A正确。B累积流图可显示看板上进行中的工作，不能直接用于挣值管理，排除。C《敏捷实践指南》P105看板面板提供一目了然的工作流、瓶颈、阻碍和整体状态信息，不用于挣值管理，排除。D水晶方法论旨在根据项目规模(项目中涉及的人员数量)以及项目的关键性来量化并提供方法严格程度选择，排除。
