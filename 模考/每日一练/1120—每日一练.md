## 第1题 (✅)

1、自从某项目开始实施以来，产品负责人一直在各个会议上询问各个产品迭代所花费的预算情况。相比产品本身，产品负责人对成本的兴趣似乎要大得多。项目经理本应尽早采取什么措施来改变产品负责人的行为？

- [ ] A.运用不同的估算方法让产品负责人对每个产品增量所花费的成本树立信心
- [ ] B.制定沟通管理计划，其中应包含各个迭代所花费预算（与计划的预算相比）的报告，以避免在会议上发生此类讨论
- [x] C.向产品负责人澄清其在敏捷项目中的角色以及敏捷会议的范围 (==正确答案==)
- [ ] D.编制总价合同，将产品负责人的注意力转到价值而非资金上

> 答案解析:
> 关键词：PO对成本的兴趣高于产品，在各个会议上询问预算情况。考察的知识点为PO的职责及敏捷会议。产品负责人的职责是将开发团队开发的产品价值最大化，包括清晰地表述产品待办列表项，对产品待办列表项进行排序等，是产品待办列表的唯一负责人。敏捷每个会议都需专注于会议的目标，目标达成之后可以立即结束，如此确保时间被适当地使用而不会造成过程中的浪费。
> C澄清PO的角色和会议范围，确保产品价值最大化，正确。
> AB未引导PO的专注于自己的职责，排除。
> D总价合同适合于需求清晰且不易发生变更的项目，排除。

## 第2题 (✅)

2、项目经理正在处理一个已经进行了 9个月的混合项目。一些项目干系人由于看不到项目带来的附加值而感到沮丧。项目经理应该做什么来证明项目的价值？

- [ ] A.为项目添加资源，以便所有迭代都能提前完成
- [ ] B.确保干系人在项目回顾中了解当前的过程挑战
- [x] C.邀请干系人参加冲刺审查会议，并回顾已完成的工作。 (==正确答案==)
- [ ] D.编写一份内容广泛的报告，重点介绍项目的成就。

> 答案解析:
> 关键词：证明价值。项目通过开发新产品或服务、解决问题或修复有缺陷或次优的特性来提供商业价值，
> D排除。Sprint评审会议包含以下内容：产品负责人说明哪些产品待办列表项已经"完成"和哪些没有"完成"；开发团队讨论在 Sprint 期间哪些工作做的很好，遭遇到什么问题以及问题是如何解决的。评审会上交付的增量是有价值的，是迈向愿景或目标的一步。
> C正确。
> A在实践中最有效的敏捷团队往往由三到九个成员组成，添加资源会增加协调的难度，排除。
> B了解挑战不能证明价值，排除。

## 第3题 (✅)

3、某项目的一位干系人一直因易怒和对项目横加挑剔而被人诟病。项目经理希望尽量降低该干系人行为对开发团队的影响。在这种情况下，项目经理应该为团队选择什么样的培训？

- [x] A.情商培训 (==正确答案==)
- [ ] B.沟通培训
- [ ] C.敏捷培训
- [ ] D.谈判培训

> 答案解析:
> 关键词：易怒，挑剔。即情绪需要管理。情商是识别、评估和管理个人情绪、他人情绪及群体情绪的能力。情商包括4个领域，其中自我意识和自我管理是在困难的项目环境中保持冷静和富有成效的必要条件。社交意识和社交技能有助于更好地与项目团队成员和干系人建立联系。
> A正确。

## 第4题 (✅)

4、一位项目经理正在开展一个软件开发项目。一位团队成员抱怨称，由于该项目中的任务都很简单，不需要进行质量控制。项日经理明白，将质量管理计划从项目中砍掉会有助于省钱，这对该客户非常重要。项目经理该做什么？

- [x] A.制定质量管理计划，因为质量管理与成本和进度计划管理同等重要。 (==正确答案==)
- [ ] B.将没有质量管理计划就开展项目登记为风险，并将节省的预算分配到管理储备之中。
- [ ] C.获得管理层的确认，团队成员拥有足够的经验，可在不进行质量控制的情况下开发软件。
- [ ] D.让客户在接受项目可交付物之后进行外部质量审计，并减少项目预算。

> 答案解析:
> 若未达到质量要求，都会给某个或全部项目相关方带来严重的负面后果,
> C排除，
> A正确。
> B中的管理储备只针对未知-未知风险，排除。
> D审计用于确定项目活动是否遵循了组织和项目的政策、过程与程序的一种结构化且独立的过程，与题干无关，排除。

## 第5题 (✅)

5、项目经理被指派领导一个敏捷项目。项目经理希望运用激励机制鼓励团队在整个项目运作期间保持高绩效。项目经理该做什么？

- [x] A.实施奖励制度，使团队保持参与和积极性。 (==正确答案==)
- [ ] B.动用管理储备为一些团队建设活动提供资金。
- [ ] C.大幅增加项目估算，为团队活动提供缓冲资金。
- [ ] D.寻找其它方法提高团队绩效。

> 答案解析:
> 大多数项目团队成员会因得到成长机会、获得成就感、得到赞赏以及用专业技能迎接新挑战，而受到激励。在建设项目团队过程中，需要对成员的优良行为给予认可与奖励。
> A正确。
> B管理储备只针对未知-未知风险，不能用于团建活动。
> C缓冲资金于激励无关，排除。
> D不同于激励的其他方法，与题干要求不符，排除。
