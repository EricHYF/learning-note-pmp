## 第1题

1、为专门的市场研发一个新产品，产品需要符合当地的健康和安全合规要求，请问项目经理应该怎么做？

- [ ] A.掌握开发新产品的原因
- [ ] B.掌握新产品开发的过程
- [ ] C.产品设计阶段考虑到合规要求
- [x] D.以上都对 (==正确答案==)

> 答案解析:
> 【解析】"选D。本题考查的是项目经理应该具备的能力：《项目管理标准》第7版P35开发新产品的原因即项目理由，解释了为什么商业需要值得投资以及为什么在此时应该满足商业需要。商业需要、项目理由和商业战略一起为项目团队提供信息，使他们能够做出知情决策，以达到或超过预期的商业价值。
> A正确。根据PMI的人才三角，项目经理应掌握多样性、创造性的方法来完成任何工作。PMI鼓励项目经理理解和采用多种工作方式，包括预测、敏捷、设计思维或其他有待开发的新实践。
> B正确。C《项目管理标准》P27管家需遵守其组织内外得到适当授权的法律、规则、法规和要求，C正确。

## 第2题

2、项目经理加入新的组织，考虑引入敏捷，他/她思考组织特征，应该如何变更？（选三个）

- [ ] A.长期预算限制和组织情况
- [x] B.转变其对待、审视评估员工的意愿 (==正确答案==)
- [x] C.短期预算限制和组织情况 (==正确答案==)
- [x] D.项目、项目集、项目组合职能集中或分散化 (==正确答案==)

> 答案解析:
> 关键词：变革。变革友好型特征的示例包括：管理层的变革意愿；组织在员工认知、审核和评估方式上做出改变的意愿；集中或分散项目、项目集和项目组合管理职能；和指标而不是长期目标。可知，
> A错误，BCD正确。

## 第4题

4、负责软件开发的经理向开发人员询问任务，开发人员表示任务已经在一周前交付，并提到，是通过特定的项目管理软件报告的，项目经理应如何管理项目软件？。

- [ ] A.研究软件了解原理
- [x] B.查询通过沟通管理计划向团队传达应该使用，开发，传输，存放项目工件，并向团队传达使用 (==正确答案==)
- [ ] C.查干系人参与计划传达应该使用，开发，传输，存放项目工件，并向团队传达使用
- [ ] D.进行使用软件开发并培训

> 答案解析:
> 关键词：通过特定项目管理软件报告。根据题干，经理不了解报告任务进展需要用什么媒介，先明确应使用哪种媒介进行沟通。考察的知识点是沟通。沟通管理计划包括：用于传递信息的方法或技术。项目经理应先查沟通管理计划确认报告应使用的沟通工具，并确保团队成员遵守。
> B先明确沟通管理计划规定的沟通媒介，再传达，正确。
> C干系人参与计划是为管理相关方期望提供指导和信息，不针对沟通，排除。
> AD应先确认软件是否为规定的沟通媒介，在B之后，排除。

## 第5题

5、一家公司正在采用混合方式开发一个移动软件应用程序，尽管进行了多次迭代，由于概念设计没有达到关键相关方的满意程度，项目进度延迟。关键相关方已经开始参加项目团队所有的每日站会。项目经理察觉到，相关方的行为使团队的士气受到了影响，也影响了团队的生产力。项目经理应该采取怎样的管理措施，能够在不影响团队士气的情况下消除关键相关方的担忧？

- [ ] A.直接安排和相关方的会议，了解相关方的担忧。
- [ ] B.安排早期回顾会议，邀请相关方参加，一起分析相关方的担忧。
- [ ] C.改用预测性方法设计并收集需求。
- [x] D.安排团队与相关方一起讨论并消除相关方的担忧。 (==正确答案==)

> 答案解析:
> 关键词：不影响团队士气的情况下消除关键相关方的担忧。可知，解决方案需要兼顾相关方和团队。
> A团队士气未解决，排除。
> BD相比，D强调讨论并消除担忧，B只强调分析，D比B更全面，D正确。
> C消极，排除。
