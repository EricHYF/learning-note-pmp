1、Scrum团队交付项目必须符合法规要求，在设计研讨会上，开发人员推荐几个方案，但无法就具体实施哪个方案而达成一致，为了解决问题，项目经理该采取哪两项？（选择两项）

- [x] A.让每个人表明自己对各个方案的同意程度。 (正确答案)
- [ ] B.让产品负责人选择最佳方案。
- [x] C.建议团队对各方案进行打分并排序的 (正确答案)
- [ ] D.审查所有方案并确定其优先使用石川图。

> 答案解析:
PMBOK第7版P28,举手表决等许多方法都采用了发散/汇聚模式。他们的目标是在同一时刻投票以充分采纳个人意见，从而最小化群体思维。A为举手表决，C是多标准决策技术，正确。D中的石川图是用来确定原因的方法，不用于决策，排除。

2、项目经理正在管理一个混合型项目，在项目执行过程中，过半的项目预算被强行分配到其他项目，请问项目经理该怎么办？

- [ ] A.和团队成员讨论，排列待办事项优先级。
- [ ] B.和发起人讨论，修改范围基准。
- [x] C.和产品负责人讨论，最小可行产品（MVP）可行性。 (正确答案)
- [ ] D.和相关干系人讨论，申请增加预算。

> 答案解析:
关键词：过半的项目预算被强行分配。代表项目预算减少，所以完成最重要的功能是首先要考虑的，C正确。B修改范围应该PO来负责，排除。A中PO负责排列待办事项优先级，而非团队成员及项目经理，排除。


第3题
3、项目正处于执行阶段，项目经理发现公司没有外联策略，社区成员不满，发起投诉，阻止项目继续推进，项目经理如何处理以提高支持度？

- [ ] A.请管理层出面协调
- [x] B.联系干系人共享产品愿景 (正确答案)
- [ ] C.请组织发言人介绍项目对干系人的意义 (错选)
- [ ] D.组织团队制定目标

> 答案解析:
关键词：没有外联策略，社区成员阻止项目推进。可推断，由于缺乏相关方参与的管理策略，造成相关方对项目支持度低，考点为相关方参与。PMBOK（P506）客户、用户和开发人员在动态的共创过程中交换信息，通常能实现更高的相关方参与和满意程度。PMI-ACP的考纲中任务6：通过建立高层级的愿景和支持性目标，在各个增量的层级(产品、可交付成果、版本、迭代)上创建共享的愿景，以协调干系人的期望并建立信任，B正确。A中的管理层协调、C中的发言人的工作内容都应是项目经理做的，消极，排除。D仅涉及团队，未涉及相关方，排除。

第4题
4、冲刺回顾会中，团队成员针对生产过程中的缺陷问题讨论，开发负责人抱怨这个缺陷问题本应该在测试阶段被发现，团队成员产生争执，且激烈起来，项目负责人如何处理？

- [ ] A.确保团队成员理解DOD (错选)
- [ ] B.使测试人员明白详细的测试是他的职责
- [ ] C.记录并上报职能经理处理
- [x] D.转移下一个话题，稍后调查缺陷原因 (正确答案)

> 答案解析:
关键词：产生争执，且激烈起来。PMBOK第7版P167有时问题会自行消失，有时讨论会变得激烈，对此人们需要一个冷静期。在这两种情况下，撤退是适当的方法。项目经理转移话题为激烈的冲突双方冷静下来。然后再根据问题处理流程:确认问题-分析问题-解决问题来处理，D正确。《敏捷实践指南》P151完成的定义(DoD)是团队需要满足的所有标准的核对单，A是具体的解决措施，在D之后，排除。B敏捷团队对输出共同承担责任，而非仅是测试人员的职责，排除。C上报职能经理，消极，排除。

- [ ] A.禁止干系人发言
- [x] B.作基本规则 (正确答案)
- [ ] C.引入高级人员
- [ ] D.强调高级人员权威

> 答案解析:
基本规则是对项目团队成员的可接受行为的预期，为团队应如何决策、举行会议和解决冲突提供指南，B正确。ACD偏消极，排除。
