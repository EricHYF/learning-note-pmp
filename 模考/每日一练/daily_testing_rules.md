# 每日一练格式优化

## 问题描述

此目录内用于记录每日一练的考卷内容

我会将每个试卷的初稿建立一个文件并粘贴原始的文本内容

请按照以下流程协助我处理试卷初稿并整理为合理的格式：

## 任务需求

- 题目标题
  - 识别每个题目的标题，如 “第1题”， “第2题”.... 在前面添加 ‘## ’ 变为 “## 第1题”， “## 第2题”。 
  - 若每个题目文本后存在 '得分：+20' 等字样，请累加这些已经获得的分数，并将所有得分的总分值添加到 文档的标题后， 如：'# 1119—每日一练 (总分:60)'， 并在题目后添加 ' ( ✅ )' 的标记, 未得分的题目在后面添加 ' ( ❌ )'
  - 识别题目文本后，在每个题目前添加 "\n---\n" 的标记
    - 原文：
        ```
        ## 第1题
        ```

    - 修改后
        ```

        ---
        ## 第1题
        ```

- 选项部分 
  - 识别每个选项， 并在前加上 '- [ ] ' 的标记
  - 识别每个选项后是否有 '正确答案' 字段，若存在并修改为 ' (==正确答案==)'
  - 若选项为正确答案，则修改前面的标记为 '- [x] '
- 答案解析
  - 识别 ‘答案解析’ 字段，并在解析字段和其后所有的解析内容前均添加 ‘> ’ 字符
  - 识别 ‘答案解析’ 后的所有解析内容，并识别解析内容中若存在单独的 'A', 'B', 'C', 'D' 等选项的解析，则在前添加 换行 + '> '字符
- 在操作所有格式替换的时候，需要先确认：
  - 之前是否已经添加过格式
  - 若没有添加过， 则直接添加格式
  - 若已经添加过，但格式不正确，则去掉格式重新添加
  - 若格式正确，则无需添加

## 触发指令

- 用户给出文档时，询问用户是否开始应用格式，用户同意后开始执行， 5 秒倒计时，之后默认开始
- 用户在输入中包含 ‘整理’， ‘格式’ 等字样时， 也需要询问用户，5 秒后自动进行

## 执行步骤

- 分析此文档的需求
- 然后查看此文档所在的文件夹，先识别并列出所有没有格式化，或者不符合格式化标准的问题，然后询问用户需要针对那些文件执行格式化的操作 （5 秒后没有选择则停止当前扫描）
- 若上一步用户没有选择和对应的输入， 则询问用户要格式化哪个文件
